The Unbundle Prompt 
XYZ is a "bundled" term. Assume it houses a lot of connotative and intangible meaning that is hard to train and understand. Your mission is to "Unbundle" and operationalize this term.

Operationalizing means to turn the phrase or word into a set of trainable and learnable and visible actions that when mastered, encompass the real meaning of the term.

For example: "Charisma" is a bundled term that stands for the feeling of warmth, power, and presence other people feel when they interact with you. The actions that it encircles include making eye contact, active listening, speaking slowly, asking questions about the other person, smiling genuinely, having a firm handshake, and setting a collaborative frame for the conversation, etc.

Provide CONCRETE examples for daily activities in work or life, business or relationships, interpersonal or mindset, in a way that someone could take action on without necessarily feeling the emotion that might naturally lead to the behavior.

Tip — start with the word that's been nodded at and not acted on. That's the most-bundled term in your head right now.

02 · The Skill

Install for Claude Code.

/unbundle walks you through the same prompt interactively. Picks one of three tracks (Workflow / Soft Skill / Belief), asks one or two context questions, then returns 5–12 daily-trainable actions. Better than the raw prompt because the tracks change the output shape — a workflow needs an SOP, a soft skill needs observable behaviors, a belief needs a one-week schedule.

⬇ Download unbundle.plugin.zip 5.9 KB

Install — two ways

  1. In Claude Code: run /plugin install and point at the downloaded unbundle.plugin.zip.
  2. Or manually: unzip into ~/.claude/plugins/ so the path is ~/.claude/plugins/unbundle/skills/unbundle/SKILL.md. Restart Claude Code.

Verify install — type /unbundle in a Claude Code session. If the skill is discovered, you'll see it ready to invoke.
