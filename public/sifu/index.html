Why it's not just a recorder

Anyone can log clicks. The value is what happens next.

01 · Decompose

Splits the doing from the knowing.

Every step is broken into the automatable action (a CLI, an API, a click) and the knowledge your agent needs to do it well. So you get a real skill, not a brittle macro.

02 · Choose the output

An agent skill, or a human SOP.

Stable and frequent? It becomes a skill your agent runs. Judgment-heavy? It becomes a human SOP with annotated screenshots. Sifu reads the workflow and tells you which.

03 · Stays yours

No cloud. No API key. No metering.

Sifu records locally and the thinking runs on your agent and subscription. Nothing leaves your Mac, and there's no model to deprecate out from under you. Open source.

Install Sifu locally so I can train my AI executive assistant.

## Platform

macOS only. Sifu uses CGEventTap and the macOS Accessibility API to observe
input events. It will not run on Linux or Windows.

## Steps

### 1 · Clone or update the repository
If `~/sifu` does not exist:
```
git clone https://github.com/heymitch/sifu.git ~/sifu
```
If `~/sifu` already exists:
```
cd ~/sifu && git pull --ff-only
```

### 2 · Install the package
```
pip install -e ~/sifu
```
This installs Sifu in editable mode. The `sifu` command becomes available.

### 3 · Run bootstrap
```
python3 -c "from sifu.install.bootstrap import run; print(run())"
```
Bootstrap creates the local library directory and prints the `next` command.
Surface the `next` value to the user verbatim.

### 4 · Grant Accessibility permission
Go to: System Settings → Privacy & Security → Accessibility
Add SifuBar and enable the toggle. Sifu will not prompt for this automatically.

### 5 · Report back
Tell the user the library path, the `next` step, and that Accessibility must be
granted before capture begins. Do not launch capture automatically — that
decision belongs to the user.
Objections, answered

The questions you're already asking.

Does my work get sent anywhere? +

No. Recording, screenshots, and the compile step all run on your Mac. Sifu has no server and makes no network calls of its own. The only thing that ever leaves is the workflow you choose to copy — and that goes to your agent, on your machine.

Do I need an API key? +

No. Sifu never calls a model. The building happens in your own agent (Claude Code, Codex) on your existing subscription. There's nothing for Sifu to meter and no key to deprecate.

Which agents does it work with? +

Any agent that can read a pasted prompt and write files — Claude Code and Codex are the tested paths. The copy payload is plain markdown plus your local files, so it's portable.

What does it actually record? +

Clicks, keystrokes, the apps you switch between, the URLs you visit, and a screenshot per step. It compiles those into a readable, editable workflow — not raw video.

Is it really free? +

Yes. Sifu is open source, MIT-licensed, local-first. Install it, fork it, keep it. The only cost is your own agent's usage when it builds the skill.
